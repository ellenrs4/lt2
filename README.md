# 🏡 Little Garden

🌱 **Little Garden** é um layout de site responsivo desenvolvido em HTML, CSS e JavaScript com foco em interface visual limpa e design voltado para apresentação de instituição educacional.  
Ele foi criado como um projeto de estudo de desenvolvimento **Front-End** para reforçar habilidades com layout, navegação e responsividade.

👉 Acesse a versão publicada: https://ellenrs4.github.io/lt2/ :contentReference[oaicite:2]{index=2}

---

## 📌 Sobre o projeto

Este projeto simula o site institucional de uma creche/escola com seções como:
- Sobre nós
- Programa
- Admissões
- Eventos
- Contato

O objetivo principal é demonstrar sua habilidade em:
✔️ Estruturar um layout visualmente limpo  
✔️ Utilizar CSS para organização e estilo  
✔️ Criar navegação funcional entre seções  
✔️ Tornar o site responsivo para dispositivos móveis

---

## 🚀 Tecnologias utilizadas

Este projeto foi desenvolvido com:

- 🟦 **HTML5** — estrutura de conteúdo
- 🟨 **CSS3** — estilização e layout
- ⚡ **JavaScript** — interatividade básica (se aplicável)
